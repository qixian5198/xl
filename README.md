# 情商口才训练工具（xl）

一个跑在本地（或 Docker）里的聊天训练工具。你和"人"对话，但每一个"人"背后是一个会**打分、点评、复盘、追问**的沟通教练，目的是训练你的**情商、口才、情感表达和临场反应**。

核心原则：**训练，不是闲聊。** 每次对话都有明确目标、即时反馈和事后复盘。

## 能做什么

- **多身份扮演**：机器人可切换不同身份（男 / 女 / 老 / 少、医生 / 程序员 / 销售 / 亲戚 / 同事……），每个身份带完整资料（性格、家庭背景、价值观、沟通风格、幽默感、专业领域等），像真人一样说话。
- **4 种训练模式**
  1. 判断机器人心情——它藏着一个隐藏的"心情状态机"，你要从言行里推断它的真实情绪。
  2. 判断机器人性格——通过对话看穿它的性格类型。
  3. 聊天问答训练——机器人主动提问 / 回应，训练你的应对。
  4. 灵魂提问——根据你资料 + 当前场景，抛出直击要害的问题。
- **逐轮评分**：每轮回复按 共情 / 清晰 / 时机 / 尊重 / 边界 五维度打分并点评。
- **暂停点评**：一键让机器人跳出角色，以教练口吻点出你哪句话好、哪句话越界、怎么改。
- **会话复盘**：结束后生成总分、亮点、问题、可直接照说的改进句式、以及"下次最该练的场景"。
- **静默搭话**：你 N 分钟不说话，机器人会主动接话（像真人那样），不冷场。
- **记忆**：记得你说过的事，下次主动接回来。
- **书籍 skill 卡**：把书蒸馏成"沟通技术卡"（如「温和拒绝」「识别控制型沟通」），机器人在点评 / 复盘 / 灵魂提问时引用，像教练用书教你。
- **随机场景 + 迁移练习**：一键生成社交场景去练，复盘后按推荐场景再来一局。

## 技术栈

| 层 | 选型 |
|:---|:---|
| 后端 | Python 3.11+ / FastAPI / SQLAlchemy |
| 前端 | 原生 HTML + CSS + JS（单页，无构建链） |
| 数据 | SQLite（单文件 `xl.db`） |
| 模型 | NVIDIA NIM（OpenAI-compatible API，模型可随时换） |
| 部署 | 本地 `uvicorn` 直接跑，或 Docker / docker-compose |

## 快速开始（本地）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密钥
cp .env.example .env
#    编辑 .env，填入你的 NVIDIA NIM key 和可用模型

# 3. 启动
python3 -m uvicorn app.main:app --port 8001
```

浏览器打开 `http://127.0.0.1:8001/`。数据库和 3 个预设身份会在首次启动时自动创建。

## 快速开始（Docker）

```bash
docker compose up -d        # 启动（数据落在 ./data/xl.db，密钥读 .env）
docker compose logs -f     # 看日志
docker compose down        # 停止
```

## 目录结构

```
app/        FastAPI 后端（数据库、LLM 封装、prompt、业务逻辑、路由）
static/     原生前端（聊天页 index.html、设置页 settings.html）
data/       Docker 模式下 SQLite 存放目录
xl.db       本地模式下 SQLite 数据库
```

## 界面

- 聊天页（`/`）：选身份 + 模式开会话，发消息、提交判断、灵魂提问、暂停点评、随机场景、静默搭话、结束并复盘。
- 设置页（`/settings.html`）：模型 / API key / 参数、我的资料、人员身份管理（增删改 + 完整资料表单）、沟通技术卡（skill）管理。

## 说明

- 首次构建会在项目根目录生成 `xl.db` 和 3 个预设身份。
- 敏感配置（API key）放在 `.env`，已被 `.gitignore` 忽略，不要提交。
